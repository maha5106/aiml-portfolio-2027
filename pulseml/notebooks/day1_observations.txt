KEY INSIGHT:
Disk and Network counters are cumulative. They count total bytes since 
the laptop was turned on. They never decrease. 

If I feed these raw numbers into a machine learning model, every new 
reading will look like an anomaly because the number keeps growing.

THE FIX FOR DAY 2:
I must calculate DELTA = current_reading - previous_reading.
This gives me "bytes per second" instead of "total bytes since boot."
Delta is what the anomaly detector will actually learn from.
